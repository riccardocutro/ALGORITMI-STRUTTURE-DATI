\hypertarget{md_README_autotoc_md20}{}\doxysubsection{Uso di Git\+Lab}\label{md_README_autotoc_md20}
Durante la scrittura del codice è richiesto di usare in modo appropriato il sistema di versioning Git\+Lab. Questa richiesta implica quanto segue\+:


\begin{DoxyItemize}
\item Il progetto di laboratorio va inizializzato \char`\"{}clonando\char`\"{} il repository del laboratorio come descritto nel file {\ttfamily \mbox{\hyperlink{Git_8md}{Git.\+md}}}.

\begin{DoxyItemize}
\item {\bfseries{Importante}}\+: Gli esercizi richiedono (fra le altre cose) di sviluppare codice generico. Implementare un algoritmo di ordinamento {\bfseries{ibrido}} che combini Quick\+Sort e Selection\+Sort in base alla dimensione dell\textquotesingle{}array da ordinare. L\textquotesingle{}algoritmo deve funzionare nel seguente modo\+:

\end{DoxyItemize}

L\textquotesingle{}ipotesi da verificare è se Selection\+Sort, pur avendo complessità O(n²), possa risultare più efficiente di Quick\+Sort su array molto piccoli a causa del minor overhead nelle operazioni elementari. \item {\bfseries{Selection\+Sort}}\+: implementare la versione classica O(n²).
\item {\bfseries{Algoritmo ibrido}}\+: deve rispettare la soglia {\ttfamily k} e passare automaticamente da un algoritmo all\textquotesingle{}altro durante la ricorsione.
